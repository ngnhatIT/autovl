Bản lưu có tên (tối đa 5 bản/slot)
Chụp lại save của một slot để dành — khôi phục được về đúng slot đó bất cứ lúc nào. Tool cũng tự tạo một bản lưu ngay trước mỗi lần nạp ghi đè, chung vào danh sách này.

Nạp save trong 4 bước

  1. Đăng nhập đúng tài khoản ở khung game bên trái.
  2. Bấm Bản offline (nạp save) trên thanh công cụ trên cùng.
  3. Sang tab Tạo/Sửa: chọn nền, chỉnh số liệu, bấm NẠP LUÔN và xác nhận bảng xem trước.
  4. Bấm Trang chính và chờ dòng "Kiểm chứng HOÀN TẤT" — nghĩa là save đã qua được vòng kiểm tra của game.

Vì sao tool chặn nạp?

Nếu ID tài khoản trong save khác tài khoản đang đăng nhập, game sẽ gạt save ngay khi vào bản chính. Tool chặn trước để bạn khỏi mất công — hãy để tool tự lấy ID acc trong form cho khớp, đừng tích ô nạp bất chấp trừ khi bạn hiểu rõ mình đang làm gì.

Nguyên tắc an toàn

Tool chạy hoàn toàn trên máy của bạn và thao tác qua giao diện thật của game. Các loại tiền do máy chủ quản lý (như Điểm Phúc Duyên) không sửa bằng file được — nạp vào cũng bị máy chủ ghi đè khi đồng bộ.

Công cụ
Xóa cache chỉ đụng bộ nhớ đệm của game để ép tải bản game mới nhất — save trong máy và đăng nhập giữ nguyên. Xuất nhật ký tạo file .txt gồm trạng thái + lịch sử thao tác, gửi file đó khi cần soi lỗi từ xa.
Mọi thao tác đều được kiểm chứng bằng save thật sau khi thực hiện.
Nhân vật trắng đúng mẫu game tự tạo: không item, không trang bị, vàng/KNB = 0, màn 1, số giết 0. Điểm tiềm năng = (cấp−1)×5, điểm kỹ năng = cấp×1 — để nguyên chưa cộng, vào game tự cộng.
Mở rương ngựa tự động
Tự bấm nút "Dùng ×10" trong popup Rương Ngựa (Hành trang) ở khung game bên trái. Đếm bằng save thật. Chạy ở Trang chính, mở sẵn popup trước khi bấm Bắt đầu.
Mua KNB tự động
Tự bấm nút ×100 trong Kỳ Trân Các (đổi ngân lượng lấy Kim Nguyên Bảo). Đếm bằng KNB thật trong save — bấm hụt là tool biết ngay. Mở sẵn Kỳ Trân Các, tab Tiện ích ở khung game trước khi chạy. Giới hạn của game: 10.000 KNB/ngày/mỗi tài khoản.
